# Profile API
This is a simple **Node.js + Express API** that returns developer profile information from environment variables, the current UTC timestamp, and a random cat fact.

## 🚀 API Endpoint
- Local (development): http://localhost:4500/me
- Production (deployed): https://task0-production.up.railway.app/me

## 📦 Example Response
{
  "email": "kkoredesemi@gmail.com",
  "name": "ALABI OLUWAFUNMILAYO MARY",
  "stack": "Node.js/Express",
  "timestamp": "2025-10-18T15:17:06.995Z",
  "fact": "In an average year, cat owners in the United States spend over $2 billion on cat food."
}

## ⚙️ Installation & Setup
git clone https://github.com/Aabifunmi40/Task0.git
cd Task0
npm install

Create a .env file in the root directory:
PORT=4500
USER_EMAIL=kkoredesemi@gmail.com
USER_NAME=ALABI OLUWAFUNMILAYO MARY
USER_STACK=Node.js/Express

Run the server:
npm run dev   # Development (with nodemon)
npm start     # Production

Test the API:
curl http://localhost:4500/me

## 🛠️ Tech Stack
Node.js  
Express.js  
Axios (fetching cat facts)  
Helmet (security headers)  
CORS  
Express Rate Limit  
dotenv  

## 🌐 Deployment
Create a file named Procfile with the following content:
web: node index.js

Then push to Railway:
git add .
git commit -m "Deploy Profile API"
git push railway main
