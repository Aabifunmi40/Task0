# Profile API
This is a simple **Node.js + Express API** that returns developer profile information from environment variables, the current UTC timestamp, and a random cat fact.
## 🚀 API Endpoint
- Local (development): http://localhost:4500/me
- Production (deployed): https://your-app-name.up.railway.app/me
## 📦 Example Response
{
  "email": "you@example.com",
  "name": "Your Name",
  "stack": "Node.js/Express",
  "timestamp": "2025-10-18T14:45:32.120Z",
  "fact": "Cats sleep 70% of their lives."
}
## ⚙️ Installation & Setup
git clone https://github.com/Aabifunmi40/Task0.git
cd Task0
npm install
Create a `.env` file:
PORT=4500
USER_EMAIL=you@example.com
USER_NAME=Your Full Name
USER_STACK=Node.js/Express
Run the server:
npm run dev   # Development (with nodemon)
npm start     # Production
Test the API:
curl http://localhost:4500/me
## 🛠️ Tech Stack
Node.js, Express.js, Axios, Helmet, CORS, Express Rate Limit, dotenv
## 🌐 Deployment
Create a file named Procfile:
web: node index.js
Then push to Railway:
git add .
git commit -m "Deploy Profile API"
git push railway main
