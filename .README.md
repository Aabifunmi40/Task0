🐱 Cat Facts API
A slick Node.js/Express API dishing out cat facts with a side of personal flair from Cat Facts API.
😺 What It Does

Serves a JSON response:
status: "success"
user: email, name, stack (from .env)
timestamp: UTC, ISO 8601 (e.g., 2025-10-16T02:23:00.123Z)
fact: Random cat fact (fallback if API purrs out)


Handles errors like a cat landing on its feet
Secured with Helmet & CORS
Rate-limited to keep the litter box clean
Configured via .env

📦 Dependencies

express: Web framework
axios: Fetches cat facts
dotenv: Env vars
cors: Cross-origin access
helmet: Security headers
express-rate-limit: Rate limiting
nodemon: Dev auto-restart

Install:
npm install express axios dotenv cors helmet express-rate-limit
npm install --save-dev nodemon

🛠️ Setup
Install: npm install
Create .env:PORT=4500
USER_EMAIL=kkoredesemi@gmail.com
USER_NAME=ALABI OLUWAFUNMILAYO MARY
USER_STACK=Node.js/Express



🚀 Run Locally

Start: npm run dev (or npm start for production)
Hit: http://localhost:4500/me
Get:{
  "status": "success",
  "user": {
    "email": "kkoredesemi@gmail.com",
    "name": "ALABI OLUWAFUNMILAYO MARY",
    "stack": "Node.js/Express"
  },
  "timestamp": "2025-10-16T02:23:00.123Z",
  "fact": "Cats can jump six times their length."
}



🔧 Env Vars

PORT: 4500
USER_EMAIL: Your email
USER_NAME: Your full name
USER_STACK: Your stack

🧪 Test It

Basic: curl http://localhost:4500/me
Headers: curl -v http://localhost:4500/me (check Content-Type: application/json)
Errors: Change API URL to https://invalid-url.com in index.js, test, expect fallback fact, revert URL
Rate Limit: while true; do curl http://localhost:4500/me; done (429 after 100 requests)
